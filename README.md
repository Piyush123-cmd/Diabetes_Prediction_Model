# 🩺 Diabetes Disease Prediction System

A Machine Learning project that predicts whether a person is diabetic or not using medical health data.

---

## 📌 Project Overview

This project is built using the **Pima Indians Diabetes Dataset** and focuses on applying core Machine Learning concepts such as:

* Data Cleaning
* Outlier Handling
* Feature Scaling
* Model Training
* Model Evaluation
* Prediction System

The main goal of this project is to classify whether a patient is diabetic (`1`) or non-diabetic (`0`).

---

## 🚀 Technologies & Libraries Used

* Pandas

## 📊 Machine Learning Concepts Used

### ✅ Data Preprocessing

* Null value checking
* Outlier detection using IQR method
* Feature scaling using `StandardScaler`

### ✅ Model Building

* Logistic Regression
* Gaussian Naive Bayes
* Bernoulli Naive Bayes

### ✅ Model Evaluation

* Accuracy Score
* Confusion Matrix
* Precision Score
* Recall Score
* F1 Score

---

## 📁 Dataset Features

The dataset contains medical-related features such as:

* Pregnancies
* Glucose
* BloodPressure
* SkinThickness
* Insulin
* BMI
* DiabetesPedigreeFunction
* Age

Target Column:

* Outcome

  * `0` = Non-Diabetic
  * `1` = Diabetic
